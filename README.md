# Brazilian E-Commerce Analysis

## 📊 Project Overview

This project focuses on analyzing Brazilian e-commerce sales data to understand business performance, customer orders, product categories, and seller performance.

The project uses **Microsoft Excel** to organize, transform, analyze, and present the data in a business-oriented way.

The analysis is designed to help answer questions related to:

* Sales and order performance
* Product category performance
* Seller performance
* Management targets
* Monthly order trends
* Business performance across different periods

---

## 🗂️ Dataset

The project contains monthly order data covering the period from **January 2017 to April 2018**.

The raw data is organized into monthly CSV files:

```text
data/
├── orders_2017-01.csv
├── orders_2017-02.csv
├── orders_2017-03.csv
├── ...
├── orders_2017-12.csv
├── orders_2018-01.csv
├── orders_2018-02.csv
├── orders_2018-03.csv
└── orders_2018-04.csv
```

The repository also contains Excel files used for different parts of the analysis:

```text
├── New Microsoft Excel Worksheet.XLSX
├── category_performance.xlsx
├── management_targets.xlsx
└── seller_performance.xlsx
```

## 🔄 Project Workflow

The project follows a typical data analysis workflow:

### 1. Data Collection

The project uses monthly e-commerce order data stored in CSV files.

### 2. Data Preparation

The raw data is prepared and organized using Excel and Power Query to make it suitable for analysis.

### 3. Data Analysis

The data is analyzed to investigate different business areas, including:

* Category performance
* Seller performance
* Order trends
* Management targets

### 4. Business Insights

The processed data is used to create analysis outputs that can help understand business performance and identify areas that require attention.

---

## 📈 Analysis Areas

### Category Performance

Analysis of product categories to understand their contribution to the overall business performance.

### Seller Performance

Analysis of seller-level performance to identify differences between sellers and monitor their results.

### Management Targets

Comparison of actual business performance with predefined management targets.

### Order Trends

Analysis of orders across different months to understand changes in business activity over time.
